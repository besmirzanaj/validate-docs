**Base URL:** `https://api.validate.al`

## Authentication

All scanning endpoints use your personal API key. Send it in the `X-API-Key` header:

```bash
curl -H "X-API-Key: your-api-key" https://api.validate.al/scans
```

Get your API key from the [portal](https://portal.validate.al).

Account management endpoints (settings, MFA) require a JWT session obtained from the portal sign-in.

## Scanning endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| `POST` | `/request-scan` | Request a new scan |
| `GET` | `/scans` | List your scans |
| `GET` | `/scans/{id}/report` | Get a scan's full report |

### Request a scan

```bash
curl -X POST https://api.validate.al/request-scan \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"target": "example.com", "scan_type": "webapp"}'
```

**Request body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `target` | string | yes | Hostname or URL to scan |
| `scan_type` | string | no | `webapp` (default), `dns-auth`, or `ip` |

**Response `201`:**

```json
{
  "scan_id": 42,
  "target": "example.com",
  "status": "pending",
  "message": "Scan queued. Check back for results."
}
```

### List scans

```bash
curl -H "X-API-Key: your-api-key" https://api.validate.al/scans
```

**Response `200`:**

```json
{
  "scans": [
    {
      "id": 42,
      "target": "example.com",
      "status": "completed",
      "has_report": true,
      "summary": "Nuclei findings (2): ...",
      "created_at": "2026-10-04T12:00:00Z"
    }
  ]
}
```

Status values: `pending` → `in_progress` → `completed` / `failed` / `cancelled`

### Get scan report

```bash
curl -H "X-API-Key: your-api-key" https://api.validate.al/scans/42/report
```

**Response `200`:** the full JSON report (see [Results](/security-scanning/results)).

Returns **`404`** if the scan doesn't exist, doesn't belong to you, or has no report yet.

## Account endpoints

These require a JWT session (obtained by signing into the portal).

| Method | Endpoint | Purpose |
|--------|----------|---------|
| `POST` | `/auth/register` | Create account |
| `POST` | `/auth/login` | Sign in (returns JWT) |
| `GET` | `/auth/me` | Current user info |
| `PUT` | `/auth/settings` | Update display name |
| `POST` | `/auth/totp/setup` | Enable two-factor authentication |
| `POST` | `/auth/totp/verify` | Verify TOTP setup |

## Health check

```bash
curl https://api.validate.al/health
```

Returns `200 OK` as plain text. No authentication required.
