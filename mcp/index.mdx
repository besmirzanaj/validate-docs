validate.al provides an MCP (Model Context Protocol) server that exposes security scanning and email validation as tools for AI agents.

## Available tools

| Tool | Description |
|------|-------------|
| `validate_email` | Check whether an email address can receive mail |
| `request_scan` | Request a security scan for a target hostname or URL |
| `list_scans` | List all scans for your account |
| `get_scan_report` | Get the full JSON report for a scan |
| `scan_types` | List available scan types and what each checks |

## Setup

Clone the repo and install with `uv`:

```bash
git clone https://github.com/besmirzanaj/validate-al-website.git
cd validate-al-website/mcp-validate-al
uv sync
```

## Configuring your MCP client

Add the server to your MCP client configuration (Claude Code, OpenCode, etc.):

<CodeGroup>
  <CodeGroupItem title="Claude Code / OpenCode">

```json
{
  "mcpServers": {
    "validate-al": {
      "command": "uv",
      "args": [
        "run",
        "--directory",
        "/path/to/validate-al-website/mcp-validate-al",
        "python3",
        "-m",
        "src.server"
      ]
    }
  }
}
```

  </CodeGroupItem>
</CodeGroup>

The API key is passed as an argument on each tool call, so no environment configuration is needed.
