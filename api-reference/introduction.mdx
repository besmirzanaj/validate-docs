<Note>
All endpoints are served from `https://api.validate.al`. The old addresses `https://validate.al/api` and `https://email.validate.al` still work for now but are deprecated; switch to `api.validate.al`.
</Note>

## Email Validation API

**Base URL:** `https://api.validate.al`

**Authentication:** send your API key in the `X-API-Key` header. See [Authentication](/email-validation/authentication).

**Format:** requests and responses are JSON (`Content-Type: application/json`).

| Endpoint | Purpose |
|---|---|
| `POST /validate_email` | Check one email address. |
| `GET /healthz` | Service health check. No key needed; answers `OK` as plain text. |

For what each result means, see [Results](/email-validation/results) and [Errors](/email-validation/errors).

## Portal API (Scanning & Account)

**Base URL:** `https://api.validate.al`

**Authentication:** send your API key in the `X-API-Key` header. Account endpoints require a JWT session from the portal.

| Endpoint | Purpose |
|---|---|
| `POST /request-scan` | Request a new scan. |
| `GET /scans` | List your scans. |
| `GET /scans/{id}/report` | Get a scan's full report. |
| `POST /auth/register` | Create an account. |
| `POST /auth/login` | Sign in (returns JWT). |
| `GET /auth/me` | Current user info. |
| `PUT /auth/settings` | Update display name. |
| `POST /auth/totp/setup` | Enable two-factor authentication. |
| `POST /auth/totp/verify` | Verify TOTP setup. |
| `GET /health` | Health check. No key needed. |

See [Portal API](/api-reference/portal-api) for full details.
