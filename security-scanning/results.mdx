Scan reports are JSON objects with the following structure:

```json
{
  "scan_id": 42,
  "target": "example.com",
  "scan_type": "webapp",
  "status": "completed",
  "scanned_at": "2026-10-04T12:00:00Z",
  "summary": "Nuclei findings (2): CVE-2023-...",
  "raw": {
    "target": "example.com",
    "scan_type": "webapp",
    "nuclei": "... raw tool output ...",
    "nikto": "...",
    "whatweb": "...",
    "dirsearch": "...",
    "sqlmap": "..."
  }
}
```

## Fields

| Field | Description |
|-------|-------------|
| `scan_id` | Unique scan identifier |
| `target` | The hostname or URL scanned |
| `scan_type` | Type of scan performed (`webapp`, `dns-audit`, `ip`) |
| `status` | `pending` (queued), `in_progress` (a scanner is running it), then `completed`, `failed` (every tool failed; doesn't count against your allowance) or `cancelled` |
| `scanned_at` | ISO 8601 timestamp when the scan finished |
| `summary` | Human-readable summary of key findings, one per line. A tool that failed (timeout, missing, error) appears as `nuclei: failed (reason)` and its output is never counted as findings. |
| `raw` | Object containing each tool's raw output |

## Checks and score

`GET /scans/{id}/report` returns the report above under `report`, next to the scan's `status` and a ranked reading of it:

```json
{
  "scan_id": 42,
  "target": "example.com",
  "status": "completed",
  "score": { "value": 7.5, "band": "warn" },
  "checks": [
    {
      "id": "dns_audit--dnssec",
      "name": "DNSSEC",
      "status": "warning",
      "summary": "Status: unsigned",
      "description": "Cryptographic signing of the zone.",
      "why": "An unsigned zone lets an attacker forge answers for resolvers that cache them.",
      "action": "Enable DNSSEC at the DNS provider and publish the DS record at the registrar.",
      "owner": "Domain registrar and DNS provider",
      "evidence": { "findings": [{ "label": "Status", "value": "unsigned" }] },
      "duration_ms": null
    }
  ],
  "report": { "...": "the report object above" }
}
```

Each check has a `status` (`passed`, `warning`, `failed` or `info` for informational sections), a `summary` of what was found and, when it needs attention, `why` it matters, what to do (`action`) and who can fix it (`owner`). `score` runs from 0 to 10: each failed finding costs 1.5 and each warning 0.5. It's a guide, not a guarantee, and is `null` when nothing can be ranked. The portal shows exactly these values.

Today `dns-audit` scans (and the OSINT sections of other scans) are ranked. For `webapp`, `ip` and `api` scans `checks` is an empty array and `score` is `null`; read `raw` and `summary` instead. `duration_ms` is `null` for scan checks.

## Reading tool output

Each tool's output is under the `raw` key. The format varies by tool:

- **nuclei** — lists matched template names on separate lines
- **nikto** — lines starting with `+ ` indicate findings
- **whatweb** — comma-separated list of detected technologies
- **dirsearch** — discovered paths with status codes
- **sqlmap** — structured output with injection details
- **dig** — DNS record lines (A, MX, TXT, SPF, DKIM, DMARC)
- **dns_audit** (`dns-audit` scans) — the full zone audit as structured JSON: per-nameserver SOA/NS-recordset/AXFR/CHAOS/geo/PTR facts, the DNSSEC chain, delegation and glue checks, subdomains. See [Scan Types](/security-scanning/scan-types#dns-audit-dns-audit-scan) for what each field means
- **curl** — HTTP response headers
- **nmap** — open ports with service and version info

## Cancelling a scan

To cancel a pending or running scan, contact [scan@validate.al](mailto:scan@validate.al). Cancelled scans show `cancelled` status, have no report, and don't count against your daily allowance.

## Deleting scans

Delete a finished scan from the [portal](https://portal.validate.al) (**Scans → Delete**) or with `DELETE /scans/{id}`. The scan disappears at once and is removed for good, with its report and target, 10 days later. Until then, [scan@validate.al](mailto:scan@validate.al) can restore it. A deleted scan still counts towards the allowance of the day it ran.
