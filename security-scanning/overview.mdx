## How it works

1. **Request a scan** — send your target and scan type via API
2. **Scan is queued** — a scanner picks it up within seconds
3. **Scanner runs tools** — depending on scan type, one or more security tools execute
4. **Results are stored** — the full JSON report is saved and available via the API
5. **Retrieve results** — pull the report from the scans endpoint
